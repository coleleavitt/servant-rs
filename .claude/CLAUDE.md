# Claude Runtime Files

This directory contains Claude-specific prompts, rules, agents, and skills for the `servant-rs` rewrite.

Keep durable project guidance in the root `CLAUDE.md`. Keep focused always-on rules in `.claude/rules/`. Keep reusable slash-command prompts in `.claude/commands/`. Keep subagent prompts in `.claude/agents/`. Keep larger repeatable workflows in `.claude/skills/*/SKILL.md`.

Do not move Haskell reference material from `research/servant/` into this directory. Reference it by path.
